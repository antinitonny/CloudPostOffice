# ☁️ 云朵邮局（Cloud Post Office）

## 项目简介
**云朵邮局（Cloud Post Office）** 是一款基于虚幻引擎 5 开发的轻量级治愈系平台小游戏。
游戏以主角木小树护送信件前往云朵邮局为核心主线，搭配NPC对话剧情与两段式关卡设计，强调 **低压力、短时体验、零门槛操作**。玩家操控角色沿固定路线闯关，与NPC交互推进剧情、躲避乌云障碍，最终抵达邮局完成送信任务。
整个游戏没有战斗、没有复杂解谜、没有数值成长系统，目标是为玩家提供一种轻松、安静、解压的游戏体验。

# 🌤️ 设计背景
## 1. 市场痛点
当前多数游戏存在以下问题：
- 操作复杂，新手学习成本高
- 高难度机制容易造成挫败感
- 长时间游玩容易产生疲劳与焦虑
- 缺少真正适合碎片化时间的轻量小游戏
因此，本项目希望打造一款：
- 可以在几分钟内完成游玩的小游戏
- 不需要学习复杂机制
- 不制造紧张感与失败压力
- 以氛围感、剧情陪伴感为核心体验的作品
---
# 🎯 设计目标
## 核心目标
- 打造轻量解压分段闯关体验
- 实现“零门槛”操作
- 降低失败惩罚，提升游玩容错
- 新增NPC剧情交互，丰富故事沉浸感
- 用天气、场景与特效营造治愈氛围

# 🧩 核心设计规则
## 1. 简化操作
游戏仅保留最基础的移动功能：
- 无战斗
- 无解谜
- 无收集
- 无技能
- 无养成
玩家核心任务：
> 操控木小树接取送信任务，闯过两段关卡抵达云朵邮局

## 2. 单一路线分段关卡
游戏采用固定路线、两段式关卡设计：
- 无分支地图、无复杂路线选择，降低玩家决策压力
- 第一关：剧情限定关卡，触碰乌云强制返回起点
- 第二关：常规闯关地图，通过蘑菇屋传送解锁

## 3. 轻量化失败惩罚
- 第一关触碰乌云：直接返回本关起点，强轻度障碍约束
- 全局支持R键重生至最近存档点，无需从头重开
- F键全局随时暂停，灵活控制游玩节奏
---
# 🕹️ 游戏规则
## 胜利条件
完成两段关卡，成功将信件送至终点邮局。

## 失败/惩罚机制
1. 第一关触碰黑乌云：立即返回第一关起点
2. 掉落、超时等意外情况：按R键重生至最近存档点

## 特殊机制
1. NPC对话交互：靠近NPC自动触发对话，解锁任务与传送权限
2. 蘑菇屋传送：与蘑小菇对话完成后，蘑菇屋开启传送，跳转第二关邮局地图
3. 存档机制：沿途自动记录存档点，R键一键回到最近存档位置
4. 全局暂停：任意游戏阶段按F键打开暂停界面

# 🎮 操作方式
| 按键 | 功能 |
|---|---|
| W | 前进 |
| S | 后退 |
| A | 左移 |
| D | 右移 |
| 空格 | 跳跃 |
| F | 全局暂停游戏 |
| R | 重生至最近存档点 |

## 操作特点
- 无攻击、无技能、无额外交互按键
- NPC对话、场景传送均为自动触发，无需手动交互
